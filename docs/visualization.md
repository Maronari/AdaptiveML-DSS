# Визуализация

## Текущее состояние

Сейчас в проекте есть два визуальных слоя:

- встроенный минимальный UI, который раздается FastAPI на `/app/`;
- генератор статического HTML-отчета:
  `scripts/render_visual_report.py`

Через UI можно:

- создать и удалить проект;
- загрузить датасет и обучить модель;
- выполнить переобучение;
- просмотреть историю моделей проекта;
- переключить активную версию модели;
- открыть график истории и прогноза;
- менять горизонт прогноза ползунком от `10 минут` до `24 часов`;
- менять количество отображаемых forecast-точек;
- сравнить `actual vs predicted`.

HTML-отчет остается удобным способом офлайн-анализа результатов уже обученной модели.

## Что входит в отчёт

HTML-репорт содержит:

- карточки с метриками;
- график распределения target;
- график feature importance;
- график `actual vs predicted`;
- график top factors из explainability;
- sample prediction/explanation blocks;
- sample DSS recommendations;
- сырые метаданные по модели и схеме.

## Где сохраняется отчёт

По умолчанию:

- `storage/artifacts/<project-id>/visual-report.html`

Пример для текущего `demo` проекта:

- `storage/artifacts/demo/visual-report.html`

## Генерация

```bash
python scripts/render_visual_report.py \
  --project-id demo \
  --sample-size 40
```

## Почему sample-size важен

Explainability внутри отчёта использует SHAP.

Из-за этого:

- маленький `sample-size` собирается быстро;
- большой `sample-size` заметно замедляет генерацию;
- для повседневной проверки разумно использовать `40`;
- для более насыщенного отчёта можно использовать `120` и выше.

## Экран графика

Страница `/app/graph.html` сейчас уже не сводится к статичному просмотру одного графика.

Она умеет:

- показывать историю и прогноз выбранной версии модели;
- переключать горизонт прогноза линейным ползунком;
- менять количество отображаемых точек отдельным ползунком;
- прокручивать и масштабировать график;
- открывать прогноз конкретной версии модели из истории проекта.
