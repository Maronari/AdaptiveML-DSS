# AdaptiveML-DSS

AdaptiveML DSS — это платформа автоматизированного машинного обучения и поддержки принятия решений для табличных данных.

Система позволяет загружать пользовательские датасеты, автоматически обучать и сравнивать несколько моделей, выполнять предсказания на новых данных, формировать рекомендации для принятия решений и контролируемо переобучать модели при поступлении новых наблюдений.

## Основные возможности

- загрузка и валидация табличных датасетов;
- автоматическое определение структуры данных и типа задачи;
- автоматическое построение и обучение нескольких ML-моделей;
- выбор лучшей модели по метрикам качества;
- выполнение предсказаний на новых данных;
- генерация объяснений и рекомендаций в рамках СППР;
- хранение версий датасетов и моделей;
- контролируемое переобучение модели на новых данных;
- мониторинг качества входных данных и изменений распределений.

## Назначение проекта

Проект предназначен для автоматизации работы с пользовательскими данными в задачах анализа и прогнозирования. Платформа ориентирована на сценарии, в которых пользователь не хочет вручную строить весь пайплайн машинного обучения, а ожидает получить готовую модель и поддержку принятия решений на ее основе.

Система может использоваться в образовательных, исследовательских и прикладных задачах, связанных с прогнозированием, оценкой рисков, классификацией объектов и анализом факторов, влияющих на целевой показатель.

- мультимодальных данных.

## Архитектура системы

Система состоит из следующих основных модулей:

### 1. Модуль загрузки и валидации данных
Отвечает за:
- прием пользовательских датасетов;
- проверку формата и структуры;
- определение типов признаков;
- поиск пропусков, дубликатов и аномалий;
- формирование версии датасета.

### 2. Модуль AutoML
Отвечает за:
- определение типа ML-задачи;
- построение preprocessing pipeline;
- обучение нескольких моделей-кандидатов;
- подбор гиперпараметров;
- оценку качества моделей;
- выбор лучшей модели.

### 3. Реестр моделей и датасетов
Отвечает за:
- хранение версий датасетов;
- хранение версий обученных моделей;
- хранение метрик, параметров и артефактов;
- поддержку жизненного цикла модели.

### 4. Сервис предсказаний
Отвечает за:
- проверку совместимости новых данных со схемой модели;
- выполнение предсказаний;
- возврат результата пользователю.

### 5. Модуль СППР
Отвечает за:
- интерпретацию предсказаний;
- выделение факторов, влияющих на результат;
- формирование рекомендаций для пользователя;
- применение бизнес-правил поверх вывода модели.

### 6. Модуль мониторинга и переобучения
Отвечает за:
- анализ новых данных;
- контроль drift-сценариев;
- запуск повторного обучения;
- сравнение новой модели с текущей;
- обновление активной версии модели.

## Принцип работы

1. Пользователь создает проект.
2. Загружает исходный датасет.
3. Выбирает целевой признак.
4. Система анализирует данные и запускает AutoML.
5. Обучаются несколько моделей-кандидатов.
6. Лучшая модель сохраняется как активная.
7. Пользователь загружает новые данные для предсказания.
8. Система возвращает прогноз, объяснение и рекомендацию.
9. При поступлении новых размеченных данных система может запустить переобучение.
10. Если новая версия модели показывает лучшие результаты, она становится активной.

## Пример сценария использования

### Обучение модели
Пользователь загружает датасет с историческими данными, выбирает целевую переменную и запускает обучение. Система автоматически подготавливает данные, обучает несколько алгоритмов и выбирает лучшую модель.

### Предсказание
Пользователь загружает новые записи без целевого признака. Система выполняет предсказание и возвращает результат.

### Поддержка принятия решений
На основе предсказания и анализа факторов система формирует рекомендацию, например:
- высокий риск отказа оборудования;
- наиболее влияющие параметры: температура, ток, вибрация;
- рекомендация: снизить нагрузку и провести диагностику узла.

### Переобучение
Пользователь загружает новые данные с известными фактическими результатами. Система проверяет качество новых данных, запускает повторное обучение и сравнивает новую модель с текущей.
