# Фронтенд

В репозитории уже есть минимальный статический фронтенд, который раздается самим FastAPI.

Открыть его можно по адресу:

- `http://localhost:8000/app/`

Текущий сценарий работы:

- открыть страницу графика по `http://localhost:8000/app/`;
- перейти на отдельную страницу обучения;
- загрузить датасет `csv/xlsx` и выполнить валидацию;
- обучить модель через `/training/run/file`;
- сравнить `actual` и `predicted`;
- выполнить контролируемое переобучение на новых данных;
- вернуться на страницу графика и просмотреть сохраненный результат сравнения.

Текущий UI не требует отдельных npm-зависимостей и расположен в файлах:

- `frontend/index.html` - страница с графиком предсказаний;
- `frontend/training.html` - страница запуска обучения и сравнения;
- `frontend/styles.css`
- `frontend/app.js` - логика страницы графика;
- `frontend/training.js` - логика страницы обучения.

Если позже понадобится более сложный клиент, этот слой можно перенести в полноценное приложение на современном фронтенд-стеке.
